Latent NODE Key Findings

Latent dimension is the critical hyperparameter. z=16 is too compressed (R²=0.37), z=32 is marginal (R²=0.44–0.63), but z=64 breaks through (R²=0.93+). This confirms that the 50-channel observations lie on a ~64-dimensional manifold that benefits from denoising before ODE integration.

Skip Connections Key Findings

The noskip baseline (pure CA-NODE, R²=0.9009) remains the best channel-level model. Adding skip connections consistently degrades test R² due to overfitting. Heavy weight decay (swd=1.0) on skip layers achieves R²=0.8911, the best among skip variants but still -1.1% below pure ODE. This confirms that direct feedforward paths bypass ODE's regularizing continuity constraint without offering predictive advantage.

Sequence Models Key Findings

Control-Affine inductive bias is critical. The Euler-discretized CA-NODE (R²=0.8968 with lr=5e-5) dramatically outperforms the black-box GRU (R²=0.5798) despite using the same number of parameters. The GRU memorizes training windows perfectly (train loss 0.055) but generalizes terribly to test trials, while the x_next = x + f(x) + g(x)u structure prevents overfitting. The discrete CA-NODE slightly trails the continuous solver (0.9009), confirming that adaptive ODE integration adds ~0.5% over single Euler steps when both use optimal LR.

Key Findings

Research Insights
🧬

Latent Denoising Breaks the R²≈0.90 Ceiling

Projecting 50 channels → z=64 latent dimension filters channel-level noise while preserving the dynamical manifold. R² jumps from 0.9009 to 0.9387 (+4.2% absolute). z=32 is too compressed; z=64 is the sweet spot.

⚡

Control-Affine Bias is Essential

Discrete CA-NODE (R²=0.8744) dramatically outperforms GRU (R²=0.5798) with the same parameter count. The dx = f(x) + g(x)u structure prevents overfitting by encoding physics priors. Black-box RNNs memorize training noise.

🔬

Continuous > Discrete Integration

Adaptive ODE solvers (dopri5, R²=0.9009) outperform single Euler steps (R²=0.8744) by +2.6%. Multi-step adaptive integration captures smooth dynamics more accurately than fixed-step forward Euler.

🚫

Skip Connections Hurt

All skip variants degrade test R². Even with heavy weight decay (swd=1.0), skips only reach R²=0.8911 vs 0.9009 baseline. Direct feedforward paths bypass the ODE's regularizing continuity constraint.

📡

Spectral Loss: No Effect

Adding FFT-magnitude loss (α=0.01→2.0) provides zero improvement. All variants cluster at R²≈0.899. The time-domain MSE already captures frequency content implicitly. Idea ruled out.

🔮

Causal Forecasting is Hard

Restricting the encoder to only see past context (causal) drops R² from 0.94 to 0.53. Non-causal smoothing (seeing the full trial) is dramatically easier. Longer context (50→100ms) helps slightly but the gap remains large.
